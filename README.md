# SwiftCargo React homepage

## Run locally
1. Install Node.js.
2. Extract this folder.
3. Open a terminal in this folder and run `npm install`.
4. Run `npm run dev`.
5. Open the local URL shown by Vite.

## Notes
- The page is a front-end homepage prototype.
- Navigation links scroll to sections on the same page; they do not open separate pages.
- The contact form currently demonstrates client-side interaction only. It does not send email or save messages. Connect it to your backend/API before launch.
- Replace the social media URLs and email with the official SwiftCargo accounts.
- Images are loaded from Unsplash and require an internet connection.
